# Welcome to your Expo app 👋

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

In the output, you'll find options to open the app in a

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go), a limited sandbox for trying out app development with Expo

## Push notifications

On iOS and Android, the dashboard requests notification permission and registers an Expo push token. Use a development or production build to test remote push; Expo Go does not support remote push on Android. Configure Android FCM v1 and iOS APNs credentials for the EAS project before sending notifications ([Expo setup guide](https://docs.expo.dev/push-notifications/push-notifications-setup/)).

The app does not currently upload its push token to a server or run market scanning while closed. The dashboard's WebSocket and signal scanning stop when the operating system suspends the app. Closed-app market alerts therefore require a backend/background worker to monitor markets and send notifications to registered tokens.

You can start developing by editing the files inside the **src/app** directory. This project uses [file-based routing](https://docs.expo.dev/router/introduction).

## Get a fresh project

When you're ready, run:

```bash
npm run reset-project
```

This command will move the starter code to the **example** directory and create a blank **src/app** directory where you can start developing.
